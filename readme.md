# 📈 Stock Market Dashboard

A modern and responsive **Stock Market Dashboard** built using **HTML, CSS, JavaScript, Chart.js, and Alpha Vantage API**. This application allows users to search stocks, view live market data, analyze price trends with charts, and maintain a personal watchlist.

---

## 🚀 Features

- 🔍 Search stocks by ticker symbol (AAPL, TSLA, MSFT, GOOGL, etc.)
- 📈 Live stock price updates
- 📊 Interactive stock price charts using Chart.js
- 💹 Current Price, Open Price, Previous Close & Daily Change
- ⭐ Personal Watchlist
- 💾 Local Storage support
- 📱 Fully Responsive Design
- ⚡ Fast and Modern User Interface
- ⌨️ Search using Enter key
- 🔄 Auto Refresh stock data
- 🌙 Professional Dark Theme

## ⚙️ Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Stock-Market-Dashboard.git
```

### 2. Open Project

Open the folder in **Visual Studio Code**.

### 3. Get Free API Key

Visit:

https://www.alphavantage.co/support/#api-key

Create a free API key.

### 4. Add API Key

Open `api.js`

Replace:

```javascript
const API_KEY = "YOUR_API_KEY_HERE";
```

with

```javascript
const API_KEY = "YOUR_API_KEY";
```

### 5. Run the Project

Open `index.html` using **Live Server**.
